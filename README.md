# Dominada — bugs and ideas

This is where you report a problem with **Dominada**, ask for something, or ask
a question.

**[Open an issue](../../issues/new/choose)** ·
**[Read about the app](https://boriken.dev/dominada/)**

## Why this repository is empty

Dominada's source is closed, and GitHub gives a private repository private
issues — there is no way to have one without the other. So the code lives
somewhere private and the conversation lives here, in the open, where you can
read what other people have already reported before writing your own.

There is no code here and there never will be.

## Reporting something that went wrong

The most useful report says what you expected and what happened instead. Two
things help more than anything else:

- **Which screen you were on**, and what you had just done.
- **Your version and device** — the version is at the bottom of *Acerca de*
  on the home screen.

If a score came out wrong, say what the hand actually was — who won, the pips
on each side, and which rule profile you were playing. That is usually enough
to reproduce it exactly.

**Please do not post a screenshot with other people's names in it** unless
they would not mind. Player names are yours and your friends', and this page
is public.

## Asking for something

Say what you are trying to do at the table, not only the feature you have in
mind — the problem is often solvable in a way nobody had thought of, and that
is lost if only the proposed solution gets written down.
